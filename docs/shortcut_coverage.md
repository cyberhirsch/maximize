# Max keymap coverage

Generated by `tools/check_max_keymap.py` from the Moritz build: every key in 3ds Max's Main UI, Edit Poly and Editable Poly tables ([shortcuts_max_maya_full.md](shortcuts_max_maya_full.md)), and what Moritz's Max keymap does with it in the 3D Viewport (Object Mode for the Main UI, Edit Mode for Edit Poly). Plan: [shortcut_plan.md](shortcut_plan.md).

- **OK**: same key, same function.
- **Conflict**: the key does something else in Moritz.
- **Unbound**: Moritz has the function but not on this key.
- **No feature**: Moritz has no matching function yet (the cell shows what the key does today).
- **Mouse**: mouse gestures and descriptions; checked by hand, not here.
